Sub-agents (in ~/.claude/agents/, backed up via brain repo)

album-fetcher
Paste a Google Photos share link → returns 25–35 best landscape URLs ready for the JerseyMark "memory" workflow.
build-validator
Curls deployed URLs, checks HTTP/SSL, verifies PIN endpoints. "Is X working?"
disk-investigator
Diagnoses C: drive bloat. Knows about Phone Link / OneDrive Samsung Gallery / Camera Roll triple-mirror trap.
morning-briefing
4-section daily digest (open loops, portfolio, news, today's queue). Also fires from a 5pm cloud Routine.
repo-explorer
"Look at this repo" / "what is X" → tight ~300-word architectural summary.
ship-it
Full deploy dance: git status → selective add → commit → push → poll Vercel → curl-verify the live HTML.
vercel-doctor
Per-project Vercel health: deploys, domains, SSL, env vars present. Read-only.
